### Notes
- Meshy is the priority 3D vendor: text/image→3D, AI texturing, auto-rig/animation,
  **MCP server** ("Generate 3D inside Claude, Cursor…"), CLI, API. One integration covers
  generation + texture + rig.
- Tripo similar API; exact prices UNKNOWN (official page JS-rendered/blocked).
- Local reconstruction = €0 but quality/effort variable; good fallback.
- Generation fallback chain: Meshy → Tripo → local → client-supplied GLB.

### Formats
- GLB (preferred, single binary), GLTF, USDZ (Apple AR). All handled by Three.js/R3F.

### Configurators / interactive 3D
- Product configurator: Three.js + client GLB + state UI (FREE).
- Hotspots/annotations: Three.js raycasting (FREE).
- 3D viewer with lazy-load + draco compression (FREE).

## C. 3D USE CASES vs BUDGET
- €0: Three.js + client GLB + open models (Poly Haven CC0, Sketchfab CC).
- €1–€5: one hero model via Meshy/Tripo low credits.
- €5–€20: Meshy Studio for multiple product models + Spline scenes.

## D. REJECT
- generic 3D blobs, aimless WebGL, 3D with no business purpose → see 15_REJECT_LIST.
- Heavy WebGL on low-value pages → degrades mobile perf; gate behind evidence.

## E. LOCAL FALLBACK
Three.js + procedural geometry + client models. Always available, $0, no vendor risk.
