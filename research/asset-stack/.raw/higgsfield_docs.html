Submit a request to a model endpoint, then poll for the result or receive a webhook when processing finishes. Get an API key Create and manage server-side credentials in Higgsfield Cloud. ​ Make a request Every model uses the same authentication and asynchronous request lifecycle. The JSON body depends on the selected model. cURL curl --request POST \ --url https://platform.higgsfield.ai/higgsfield-ai/soul/standard \ --header "Authorization: Key ${ HF_API_KEY_ID }:${ HF_API_KEY_SECRET }" \ --header "Content-Type: application/json" \ --data '{ "prompt": "Editorial portrait in soft daylight", "aspect_ratio": "4:3", "resolution": "720p" }' The API immediately returns a request identifier and links for checking or canceling the request. { "status" : "queued" , "request_id" : "d7e6c0f3-6699-4f6c-bb45-2ad7fd9158ff" , "status_url" : "https://platform.higgsfield.ai/requests/d7e6c0f3-6699-4f6c-bb45-2ad7fd9158ff/status" , "cancel_url" : "https://platform.higgsfield.ai/requests/d7e6c0f3-6699-4f6c-bb45-2ad7fd9158ff/cancel" } ​ Choose your path Build a prototype Use the Python or TypeScript SDK to submit a request and wait for its result.
