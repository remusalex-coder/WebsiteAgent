- **License:** MIT. [VERIFIED — npm `three@0.185.1` license MIT]

## 3. WHEN 3D IS FUNCTIONALLY VALUABLE vs DECORATIVE

### Functionally valuable — concrete triggers (ship 3D when a user can *do* something with it)
- **Product viewer** — rotate / zoom / inspect a real product (e-commerce, spec sheets). [INFERRED — functional]
- **Configurator** — customize color / parts / materials (cars, furniture, apparel, PCBs). [INFERRED]
- **Property / space walkthrough** — real-estate virtual tour, navigable floor plan. [INFERRED]
- **Interactive object** — let users manipulate a mechanism to understand it. [INFERRED]
- **Educational visualization** — anatomy, physics, geometry you can explore. [INFERRED]
- **Technical explanation** — cutaway / exploded view / how-a-system-works. [INFERRED]
- **Immersive storytelling** — museum, brand narrative where spatial exploration carries meaning (justify the budget; borderline — require a user task). [INFERRED]

### REJECT 3D as decorative — do NOT ship when
- Hero spinners, floating blobs, abstract background shapes that add no information. [INFERRED]
- "Wow factor" only — no user task, no information gain. [INFERRED]
- Low-end / mobile perf budget is tight and the 3D does not pay for its cost. [INFERRED]
- It conflicts with accessibility / `prefers-reduced-motion` and you cannot provide a graceful fallback. [INFERRED]
- Lighthouse / SEO / load-time hit outweighs the value. [INFERRED]
- A static 2D image, illustration, or short video communicates the same thing. [INFERRED]
- The subject is inherently 2D (UI motion, icons) — use Rive instead of a 3D engine. [INFERRED]

**Decision rule:** ship 3D only when a user can *inspect, configure, navigate, or learn* something a 2D asset cannot; otherwise use a poster image / video or a lightweight 2D interaction (Rive). [INFERRED]
